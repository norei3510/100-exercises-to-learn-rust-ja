# 日本語版について

このサイトは、Mainmatter GmbH（原著者: Luca Palmieri）による
「100 Exercises To Learn Rust」の**非公式AI日本語翻訳版**です。

## 教材の使い方

1. 左の目次から順に本文を読みます。前後のページには矢印でも移動できます。
2. 各章末の「演習」リンクで、日本語版リポジトリの対応するコードを確認します。
3. 手元のPCで演習を編集し、リポジトリのルートで `wr` を実行して解答を確認します。

準備の詳細は[「ようこそ」](01_intro/00_welcome.md#structure)を参照してください。
ブラウザ内で演習コードの編集・採点を行う機能はありません。
