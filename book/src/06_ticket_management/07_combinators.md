# コンビネータ

イテレータは、`for` ループよりもはるかに多くのことが可能です！\
`Iterator` トレイトのドキュメントを見ると、イテレータをさまざまな方法で変換、フィルタリング、結合するために活用できる**膨大な**メソッド群が見つかります。

代表的なものをいくつか挙げます：

- `map` は、イテレータの各要素に関数を適用します。
- `filter` は、述語を満たす要素のみを保持します。
- `filter_map` は、`filter` と `map` を一度に組み合わせます。
- `cloned` は、参照のイテレータを値のイテレータに変換し、各要素をクローンします。
- `enumerate` は、`(index, value)` ペアを生成する新しいイテレータを返します。
- `skip` は、イテレータの先頭 `n` 個の要素をスキップします。
- `take` は、`n` 個の要素の後でイテレータを停止します。
- `chain` は、2つのイテレータを1つに結合します。

これらのメソッドは**コンビネータ**と呼ばれます。\
通常、これらを**チェーン**させることで、簡潔で読みやすい方法で複雑な変換を実現します：

```rust
let numbers = vec![1, 2, 3, 4, 5];
// 偶数の2乗の和
let outcome: u32 = numbers.iter()
    .filter(|&n| n % 2 == 0)
    .map(|&n| n * n)
    .sum();
```


<a id="closures"></a>

## クロージャ

上記の `filter` と `map` メソッドはどうなっているのでしょうか？\
これらは引数として**クロージャ**を受け取ります。

クロージャとは**無名関数**、つまり私たちが慣れ親しんでいる `fn` 構文を用いて定義されない関数のことです。\
クロージャは `|args| body` 構文を用いて定義され、`args` が引数、`body` が関数本体となります。
`body` はコードブロックまたは単一の式になります。
例えば：

```rust
// 引数に1を加算する匿名関数
let add_one = |x| x + 1;
// ブロックを使って記述することも可能です：
let add_one = |x| { x + 1 };
```


クロージャは複数の引数を取ることができます：

```rust
let add = |x, y| x + y;
let sum = add(1, 2);
```


また、周囲の環境から変数をキャプチャすることもできます：

```rust
let x = 42;
let add_x = |y| x + y;
let sum = add_x(1);
```


必要に応じて、引数の型や戻り値の型を指定できます：

```rust
// 入力タイプのみ
let add_one = |x: i32| x + 1;
// または、`fn`構文を用いて入出力型の両方を指定します。
let add_one: fn(i32) -> i32 = |x| x + 1;
```


<a id="collect"></a>

## `collect`

コンビネータを使ってイテレータの変換が終わったらどうなるでしょうか？\
変換後の値を `for` ループで反復処理するか、あるいはコレクションに収集します。

後者は `collect` メソッドを使用して行います。\
`collect` はイテレータを消費し、その要素を任意のコレクションに収集します。

例えば、偶数の2乗を `Vec` に収集できます：

```rust
let numbers = vec![1, 2, 3, 4, 5];
let squares_of_evens: Vec<u32> = numbers.iter()
    .filter(|&n| n % 2 == 0)
    .map(|&n| n * n)
    .collect();
```


`collect` は**戻り値の型**に関してジェネリックです。\
そのため、通常はコンパイラが正しい型を推論できるよう、型ヒントを提供する必要があります。
上記の例では、`squares_of_evens` の型を `Vec<u32>` としてアノテーションしました。
あるいは、**ターボフィッシュ構文**を使用して型を指定することもできます：

```rust
let squares_of_evens = numbers.iter()
    .filter(|&n| n % 2 == 0)
    .map(|&n| n * n)
    // ターボフィッシュ構文: `<method_name>::<type>()`
    // `::<>`が魚のように見えるため、ターボフィッシュと呼ばれています。
    .collect::<Vec<u32>>();
```
