# 値のコピー（パート1）

前章では、所有権と借用について紹介しました。\
特に、以下の点について述べました。

- Rustのあらゆる値は、いかなる時点においても単一の所有者を持ちます。
- 関数が値の所有権を取得する（「値を消費する」）と、呼び出し元はその値をそれ以上使用できなくなります。

これらの制約は、時に制限となることがあります。\
値の所有権を取得する関数を呼び出す必要があるが、その後もその値を使用したいという
場面があるかもしれません。

```rust
fn consumer(s: String) { /* */ }

fn example() {
     let mut s = String::from("hello");
     consumer(s);
     s.push_str(", world!"); // エラー: ムーブ後にここで値が借用されています
}
```


そこで `Clone` の出番です。

<a id="clone"></a>

## `Clone`

`Clone` はRustの標準ライブラリで定義されているトレイトです。

```rust
pub trait Clone {
    fn clone(&self) -> Self;
}
```


そのメソッドである `clone` は、`self` への参照を受け取り、同じ型の新しい**所有された**インスタンスを返します。

<a id="in-action"></a>

## 実際の使い方

先ほどの例に戻り、`consumer` を呼び出す前に `clone` を使用して新しい `String` インスタンスを作成できます。

```rust
fn consumer(s: String) { /* */ }

fn example() {
     let mut s = String::from("hello");
     let t = s.clone();
     consumer(t);
     s.push_str(", world!"); // エラーなし
}
```


`s` の所有権を `consumer` に渡す代わりに、（`s` をクローンして）新しい `String` を作成し、
それを `consumer` に渡します。\
`s` は `consumer` の呼び出し後も有効なままであり、引き続き使用可能です。

<a id="in-memory"></a>

## メモリ上の動作

先ほどの例で、メモリ上で何が起きたかを見てみましょう。
`let mut s = String::from("hello");` が実行されると、メモリは次のようになります。

```text
                    s
      +---------+--------+----------+
Stack | pointer | length | capacity | 
      |  |      |   5    |    5     |
      +--|------+--------+----------+
         |
         |
         v
       +---+---+---+---+---+
Heap:  | H | e | l | l | o |
       +---+---+---+---+---+
```


`let t = s.clone()` が実行されると、データのコピーを格納するために、ヒープ上に新しい領域が割り当てられます。

```text
                    s                                    t
      +---------+--------+----------+      +---------+--------+----------+
Stack | pointer | length | capacity |      | pointer | length | capacity |
      |  |      |   5    |    5     |      |  |      |   5    |    5     |
      +--|------+--------+----------+      +--|------+--------+----------+
         |                                    |
         |                                    |
         v                                    v
       +---+---+---+---+---+                +---+---+---+---+---+
Heap:  | H | e | l | l | o |                | H | e | l | l | o |
       +---+---+---+---+---+                +---+---+---+---+---+
```


Javaのような言語に慣れている方にとって、`clone` はオブジェクトのディープコピーを作成する方法だと考えることができます。

<a id="implementing-clone"></a>

## `Clone` の実装

ある型を `Clone` 可能にするには、その型に対して `Clone` トレイトを実装する必要があります。\
ほとんどの場合、`Clone` は derive することで実装します。

```rust
#[derive(Clone)]
struct MyType {
    // フィールド
}
```


コンパイラは、予想通り `MyType` に対して `Clone` を実装します。具体的には、`MyType` の各フィールドを個別にクローンし、
その後、クローンされたフィールドを使用して新しい `MyType` インスタンスを構築します。\
`derive` マクロによって生成されたコードを確認するには、`cargo expand`（またはIDE）を使用できることを覚えておいてください。
